# Лабораторная работа №4
**Асинхронный исполнитель задач**

## Цель работы
Научиться реализовывать приложения с асинхронной моделью управления. Перейти от ленивой генерации задач к их конкурентному выполнению в `Event Loop` без блокировки основного потока.

## Новые возможности
- **Асинхронная очередь**: Интегрирована `asyncio.Queue` для безопасной передачи задач между потоками исполнения.
- **Контракты обработчиков (Protocol)**: Разработан строгий интерфейс `TaskHandler` через `typing.Protocol`. Это позволяет легко добавлять новые типы обработчиков без изменения ядра системы (Соблюдение Open-Closed Principle).
- **Контекстные менеджеры**: Жизненный цикл исполнителя (`AsyncExecutor`) управляется через асинхронный контекстный менеджер (`__aenter__`, `__aexit__`). Это гарантирует корректный запуск фоновых воркеров и безопасное закрытие ресурсов (graceful shutdown) даже при возникновении критических ошибок.
- **Централизованная обработка ошибок**: Фоновый воркер перехватывает кастомные исключения `TaskError` и изолирует их, не позволяя одной сбойной задаче обрушить весь Event Loop.

## Чему научился

Проектировать неблокирующую архитектуру с использованием async / await.
Понимать разницу между синхронным ожиданием (time.sleep) и передачей управления в Event Loop (asyncio.sleep).
Управлять фоновыми задачами (asyncio.create_task и cancel).
Безопасно завершать асинхронные очереди (метод join()).
